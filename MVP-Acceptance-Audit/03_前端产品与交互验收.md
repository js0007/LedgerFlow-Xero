# 03 前端产品与交互验收

> **审计方法：** 结合全部前端组件源码审阅（`app/frontend/src/`）及在独立测试环境（`http://127.0.0.1:5099/`，Chrome DevTools MCP）下的实时渲染、权限角色切换、页面导航与视口自适应实测。  
> **实测 Console 状态：** 所有访问页面均 **零 console error** **[已验证]**。

---

## 一、总体前端产品定性

- **架构现状：** React 18 + TypeScript + Vite（1585 modules 编译 `1.83s` 通过）**[已验证]**。UI 还原度达到 **Xero Classic/New Nav 混合风格**，信息密度、Twin Balances 卡片与三栏对账工作台贴合实际业务习惯。
- **核心判断：** 前端**无需推倒重做**，当前问题集中于三类典型 MVP 技术债：
  1. **契约错位（Contract Mismatch）：** 多处字段或接口调用与后端真实契约不一致导致弹窗/按钮必然报错；
  2. **无 URL 路由与状态持久：** 仅靠 `App.tsx` 内存 `useState<RouteKey>` 切页，刷新即回 Dashboard，浏览器后退/前进、多标签并行对账及深链接失效；
  3. **交互与细节毛刺：** `READONLY` 角色按钮暴露、巨型组件（1200–1500 行）、硬编码财年日期预设、500px 窄屏横向溢出（`scrollWidth=905 > innerWidth=500`）**[已验证]**。

## 三、UI/交互 Defects 明细卡（可直接派发修复）

1. **[UI-01 / High] COA 三连契约错误（`OVERHEADS` 400 / `Archive` 误调 `DELETE` / `"NONE"` 错位）**
   - **位置：** [AccountingWorkspaceView.tsx#L167](file:///d:/ai-work/au-faiw/xero调研/app/frontend/src/components/AccountingWorkspaceView.tsx#L167)、[#L201](file:///d:/ai-work/au-faiw/xero调研/app/frontend/src/components/AccountingWorkspaceView.tsx#L201)、[#L499](file:///d:/ai-work/au-faiw/xero调研/app/frontend/src/components/AccountingWorkspaceView.tsx#L499)。
   - **解决与验收：** 对齐前后端 `AccountType` 枚举；Archive 按钮改调 `PATCH {status:'ARCHIVED'}`；清空税率查找 `"BASEXCLUDED"` 或允许明确传 `null` 并通过单测验证。
2. **[UI-02 / Medium-High] `READONLY` 角色在 Dashboard & TopNav 仍可见写操作入口**
   - **位置：** [TopNav.tsx](file:///d:/ai-work/au-faiw/xero调研/app/frontend/src/components/TopNav.tsx)、[DashboardView.tsx#L52-L57](file:///d:/ai-work/au-faiw/xero调研/app/frontend/src/components/DashboardView.tsx#L52-L57)。
   - **解决与验收：** 在 TopNav 快捷新建与 Dashboard `New Bill` / `New Invoice` / `Reconcile` / `Import CSV` 上统一绑定 `role !== "READONLY"` 显隐或禁用；切至 `READONLY` 时全站不可点开创建表单。
3. **[UI-03 / Medium-High] 无 URL 路由导致刷新丢页 & 无法后退 / 分享链接**
   - **位置：** [App.tsx](file:///d:/ai-work/au-faiw/xero调研/app/frontend/src/App.tsx) 状态机管理。
   - **解决与验收：** 引入 `react-router-dom`（如 `/orgs/:orgShortCode/invoices`、`/orgs/:orgShortCode/banking/:bankId/reconcile`），刷新任意子页仍停留在同一页面且保留所选组织。
4. **[UI-04 / Medium] 移动端 / 半屏布局横向溢出 (`500px -> scrollWidth 905px`)**
   - **位置：** 全局 CSS 表格与顶部导航栏。
   - **解决与验收：** 表格外套 `overflow-x: auto` 容器，TopNav 在 `< 960px` 收拢为折叠抽屉菜单，`500px` 下 `scrollWidth <= innerWidth`。
5. **[UI-05 / Medium] 报表单据硬编码财年、缺少 CSV 全表导出、Quotes/PO/CashFlow 异步异常吞没**
   - **解决与验收：** 所有按钮异步请求统一包入 `try/catch` + Toast；动态计算当前日期所属 AU FY（7/1–6/30）；全部报表提供标准 CSV 导出。
