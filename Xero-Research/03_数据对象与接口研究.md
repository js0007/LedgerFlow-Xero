# 03_数据对象与接口研究

> **目标：** 对 Xero 核心业务对象进行三重视角映射——**Web UI 表单字段** × **实测内部 Web BFF 契约** × **官方 Public Accounting API 规范**，厘清多租户识别、状态机字段与财务精度契约。  
> **证据基准：** `E01-NAV`, `E04-COA`, `E06-NET`, `E16`, `E20-NET`, `E21`, `E22`, `E24`, `E28-NET`, `E29-NET`–`E38-PAGE`, [official-sources-digest.md](file:///d:/ai-work/au-faiw/xero%E8%B0%83%E7%A0%94/Xero-Research/evidence/official-docs/official-sources-digest.md)。

## 1. 公共请求契约与多租户路由头 (`[Observed]` `E06-NET`, `E21`, `E28-NET`)

Xero 所有现代 Web BFF 与 Public API 均强制显式租户隔离，严禁仅依赖 Cookie 隐式猜测账套：

| HTTP Header / 机制 | Web BFF 实测值 | Public Accounting API (`developer.xero.com`) | 设计含义 |
|---|---|---|---|
| **身份认证** | `authorization: Bearer <JWT>`（RS256，含 `xero_userid`, `global_session_id`, `scope: xero_frontend-apis`） | OAuth 2.0 Bearer Token（Access 30 分钟 + Rotating Refresh Token） | 无状态令牌鉴权 |
| **租户 UUID 隔离** | `xero-tenant-id: <ORG_UUID>` | `xero-tenant-id: <ORG_UUID>` | 单用户多组织下的强数据边界 |
| **短码路由** | `xero-tenant-shortcode: !W5gW!`（URL 路径也带 `/app/<SHORTCODE>/`） | 不适用 | 供 UI/Shell 快速切换与缓存键区分 |
| **全链路追踪** | `xero-correlation-id: <UUID>` + `traceparent` (W3C) | `Idempotency-Key`（写请求幂等头） | 审计关联与重放防重 |
| **限流与配额** | Gateway/Akamai WAF 防护 | 60 req/min、并发 5、5,000 req/day (`HTTP 429` + `Retry-After`) | 多租户限流与 `If-Modified-Since` 增量拉取 |

## 2. 核心会计与业务对象全景映射（12 大对象）

### 2.1 Organisation 与 Financial Settings
- **UI 字段 (`E03`, `E10-SNAP`)：** `DisplayName`, `LegalName`, `CountryCode (AU)`, `BaseCurrency (AUD)`, `ABN (11 位)`, `FinancialYearEndDay (30)`, `FinancialYearEndMonth (6)`, `PeriodLockDate (Standard)`, `EndOfYearLockDate (Hard Lock)`, `SalesTaxDefault (Exclusive)`, `PurchasesTaxDefault (Inclusive)`, BAS settings (`ReportingType`, `GstCalculationPeriod`, `GstAccountingMethod`)。
- **Web BFF (`E06-NET`, `E28-NET`)：**
  - `GET manual-journals-bff.xero.com/organisation-settings/organisations/<ORG_UUID>` -> `{"countryCode": "AU"}`
  - `GET go.xero.com/api/bas/statement` 嵌套 `settings`: `reportingType: "SimpleBas"`, `gstCalculationPeriod: "GstQuarterly"`, `gstAccountingMethod: "Accruals" | "Cash"`, `paygWithholdingPeriod`, `paygIncomeTaxMethod`.

### 2.2 Account（会计科目）
- **UI & DOM 实测 (`E04-PAGE`, `E04-COA`)：** `AccountID (UUID)`, `Code`（如 `"200"`, `"610"`, `"820"`）, `Name`, `Type`（`Revenue`, `Direct Costs`, `Expense`, `Current Asset`, `Inventory`, `Fixed Asset`, `Current Liability`, `Non-current Liability`, `Equity`, `Bank`）, `TaxType / defaultTaxRate`, `Description`, `ShowInExpenseClaims`, `EnablePaymentsToAccount`。
- **Bank Account 专有属性 (`!W5gW!` 创建实测)：** `bankAccountId (UUID)`, `BankAccountNumber`（AU BSB+Account）, `CurrencyCode`, `BankAccountType (BANK)`。
- **Public API 关键字段 (`[Documented]`):** `Class` (`ASSET|EQUITY|EXPENSE|LIABILITY|REVENUE`), `Status` (`ACTIVE|ARCHIVED`), `SystemAccount` (`DEBTORS|CREDITORS|GST|RETAINEDEARNINGS|BANKCURRENCYGAIN|...`), `EnablePaymentsToAccount`, `HasAttachments`。

### 2.3 TaxRate（税率与税务规则）
- **实测 Web BFF (`E06-NET`, `GET manual-journals-bff.xero.com/taxrates/organisations/<ORG_UUID>`)：**
  ```json
  {
    "name": "GST on Income",
    "taxType": "OUTPUT",
    "taxComponents": [{"name": "GST", "rate": 10, "isCompound": false, "id": "..."}],
    "reportTaxType": "OUTPUT",
    "status": "Active",
    "canApplyToAssets": true,
    "canApplyToEquity": true,
    "canApplyToExpenses": false,
    "canApplyToLiabilities": true,
    "canApplyToRevenue": true,
    "displayTaxRate": 10,
    "effectiveRate": 10
  }
  ```
- **核心洞察 (`[Observed]` `E06-NET`):** 税率对象自身携带 **`canApplyTo*` 科目适用白名单** 与 **`reportTaxType`**；AU 默认 `OUTPUT` 不能应用于 Expenses，`INPUT` 不能应用于 Revenue，从根源拦截错配税码。

### 2.4 Journal & JournalLine（总账不可变分录流）
- **实测 Reporting BFF (`E16`, `E24`, `reporting.xero.com/!W5gW!/v1/Run/1098`)：**
  - 表头：`JournalID` / `JournalNumber`（整数递增 `1, 2, 3...`）、`JournalDate`、`CreatedDateUTC (Posted Date)`、`PostedBy`、`Reference / Narration`。
  - 分录行：`AccountCode`, `AccountName`, `Debit`, `Credit`，底层序列 `sequence`（如 `19365295` 供 `ShowSubsidiary.aspx?sequence=...` 下钻）。
- **Public API (`GET /Journals`, `[Documented]`):**
  - `SourceID`（关联源业务单据 UUID）, `SourceType` (`ACCREC`, `ACCRECCREDIT`, `ACCPAY`, `ACCPAYCREDIT`, `CASHREC`, `CASHPAID`, `TRANSFER`, `MANJOURNAL`, `ACCRECPAYMENT`, `ACCPAYPAYMENT`), `JournalLines[]`: `AccountID`, `AccountCode`, `AccountType`, `NetAmount`（**正=Debit，负=Credit**）, `GrossAmount`, `TaxAmount`, `TaxType`, `TrackingCategories[]`。

### 2.5 ManualJournal（手工日记账）
- **UI 表单字段 (`E07-PAGE`, `E29-PAGE`)：** `Narration`（必填摘要）, `Date`, `AutoReversingDate`（可选，同步生成带 `Reversal: ` 前缀与 `parentManualJournalID` 的次月冲销单）, `LineAmountTypes`（`NO_TAX | EXCLUSIVE | INCLUSIVE`）, `ShowOnCashBasisReports`（bool，默认 `true`）, `Status` (`DRAFT | POSTED | VOIDED | ARCHIVED`)。
- **实测 POST BFF 契约 (`E37-PAGE`, `POST manual-journals-bff.xero.com/manualjournals/organisations/<ORG_UUID>`):**
  - 请求体：`{"date":"2026-10-15","lineAmountTypes":"NO_TAX","narration":"...","showOnCashBasisReports":true,"status":"POSTED","lines":[{"accountCode":"469","accountId":"<UUID>","accountName":"Rent","accountType":"Expense","amount":50,"id":"<UUID>","sortOrder":0,"taxAmount":0,"trackingCategories":[]}, ...]}`（**Debit 为正数，Credit 为负数**）。
  - 锁账拦截响应（`HTTP 400`）：`errors: [{"message":"The document date cannot be before the end of year lock date, currently set at 31-Oct-2026"}]`。
- **Line Grid：** `Description`, `AccountID`（前端从 BFF `/accounts` 精确过滤仅拿到 **47/54** 个科目：排除 `497,498,610,630,800,801,877` 与 `BANK` 账户，`E29-NET`）, `TaxType`（`No tax` 时锁定 `BASEXCLUDED`）, `Debit` / `Credit`, `Tracking`。

### 2.6 Contact（联系人 / 客户与供应商）
- **UI 实测 (`!VD61z` Contacts SPA & `!W5gW!` 行内新建 `E21`)：** `ContactID`, `Name`（组织内唯一显示名）, `FirstName`, `LastName`, `EmailAddress`, `TaxNumber (ABN)`, `IsCustomer`, `IsSupplier`（由发生的首张 Invoice/Bill 自动激活），`ContactGroups[]`, `DefaultSalesAccountCode`, `DefaultSalesTaxType`, `DefaultPurchaseAccountCode`, `DefaultPurchaseTaxType`, `Addresses[]`, `Phones[]`。

### 2.7 Invoice / Bill / CreditNote & Allocation（应收与应付单据及贷项核销）
- **实测 Invoicing BFF (`E21`, `POST /api/invoicing/invoice/create?intent=CreateOrUpdate`)：**
  - 请求关键结构：`ContactID`, `InvoiceNumber`（与 Sales Credit Note 共享序列，如 `INV-0001`、`INV-0002`、`CN-0003`、`E33-PAGE`）, `Date`, `DueDate`, `TaxType` (`"INCLUSIVE"` | `"EXCLUSIVE"` | `"NONE"`), `Status` (`DRAFT` vs `AUTHORISED`), `CurrencyCode` (`AUD`), `LineItems[]` (`Description`, `Quantity`, `UnitAmount`, `DiscountRate`, `AccountID`, `TaxRateID/TaxType`, `Tracking`)。
  - 返回 `Totals`: `{ "SubTotal": 100.00, "Tax": 10.00, "Amount": 110.00 }`。
- **Bills 与 Credit Note Allocation 实测 (`E32-PAGE`, `E33-PAGE`, `E35-PAGE`)：**
  - Bill（`AccountsPayable/Edit.aspx` -> `View.aspx?approved=true`）允许以 `Tax inclusive` 录入并于批准后将明细单价自动归一化展示为 `Tax exclusive`（`110.00 -> 100.00 + 10.00 GST`）。
  - Sales Credit Note（`/app/<SC>/invoicing/credit-note/view/<UUID>`）批准且客户有未结清发票时自动跳转 `/Credits/Allocate.aspx?documentID=<UUID>`；核销（`Allocation`）后 Credit Note 状态转为 `PAID`、`RemainingCredit = 0.00`，并在 GL `610 AR` 产生抵消双行（`Dr/Cr`）及在 Cash BAS 中产生正负抵消行（`E36-NET`）。
- **Public API 映射 (`Invoices` 统一承载 `Type=ACCREC` 与 `Type=ACCPAY`):** `LineAmountTypes` (`Exclusive|Inclusive|NoTax`), `Status` (`DRAFT|SUBMITTED|AUTHORISED|PAID|VOIDED`), `AmountDue`, `AmountPaid`, `AmountCredited`, `Payments[]`, `CreditNotes[]`。

### 2.8 Payment（收付款核销单）
- **实测 Bank Rec 核销 (`E22`, `POST /ajaxpro/BankRec_BankRec.ashx`)：**
  - 将银行流水行与目标 `InvoiceID`（`5ebdccc3-...`）及类型为 `SUBSTYPE/ACCREC` 绑定生成收款单并置银行行为已对账。
- **Public API (`POST /Payments`):** `Invoice: {InvoiceID}`, `Account: {AccountID/Code}`（Bank 或启用收付款的科目）, `Date`, `Amount`, `Reference`, `IsReconciled`, `Status` (`AUTHORISED|DELETED`)。

### 2.9 BankAccount / BankStatementLine / BankTransaction（银行流水与直接收支）
- **三层分离模型 (`[Observed]` `E12`, `E22`, `E23`):**
  1. `BankAccount`：对应 COA 中的 `BANK` 类型科目（保存 `StatementBalance` 与账面 `XeroBalance`）。
  2. `BankStatementLine`（外部对账单导入行）：`Date`, `Amount`（正/负）, `Payee`, `Description`, `Reference`, `ChequeNumber`, `StatementLineID`, `IsReconciled`, `ReconciledTransactionID`。
  3. `BankTransaction`（系统内部 `Receive Money` / `Spend Money` / `Transfer`）：`Type` (`RECEIVE | SPEND | RECEIVE-OVERPAYMENT | SPEND-OVERPAYMENT | RECEIVE-PREPAYMENT | SPEND-PREPAYMENT`), `Contact`, `BankAccount`, `LineAmountTypes`, `LineItems[]`, `Status` (`AUTHORISED|DELETED`), `IsReconciled`。

### 2.10 ActivityStatement / BAS（澳洲税务申报表）
- **实测 BAS BFF (`E20-NET`, `E28-NET`):**
  - `GET /api/bas/statement?year=2026&month=12` -> `statement`: `endDate`, `gst: { startDate, minJournalNumber, maxJournalNumber, totalSalesG1, gstSales1A, gstPurchases1B, includeUnfiledAmounts, adjustments, journalLineTotals }`, `totalOwedToAto8A`, `totalOwedByAto8B`, `paymentAmount9`, `status`, `userAction`。
  - `GET /api/bas/gstReport/v2?...&maxJournalNumber=3&minJournalNumber=4294967295` -> `transactions[]`: `{ sequence, journalDate, accountCode, reference, details, grossAmount: {whole, fraction, sign}, gstAmount, netAmount, gstName, taxType, basFieldNames: ["1A","G1"] }`；注意金融数值拆分为 **`{whole, fraction, sign}` 精确结构** 以免 JS 浮点误差！

### 2.11 TrackingCategory（业务分析维度）
- **UI & API 实测 (`Tracking.aspx` & Public API):** `TrackingCategoryID`, `Name`（如 `Region`）, `Status` (`ACTIVE|ARCHIVED`), `Options[]` (`TrackingOptionID`, `Name`)；账套同时 `ACTIVE` 的分类上限为 **2 个**，按明细行 `LineItem.Tracking[]` 挂接。

### 2.12 Reporting Engine（标准动态报表）
- **实测 Reporting RX 接口 (`GET /v1/Run/GetData/1098`, `POST /v1/Execute?reportUniqueName=JournalReport`):**
  - 参数载体 `ReportDataOptions`：`StartDate`, `EndDate`, `AccountingBasis` (`Accrual | Cash`), `ShowZeroBalanceAccounts`, `SortBy`, `TrackingFilter`。
  - 返回树结构：`Columns[]` + `Section.GridContainer, RX` + `Section.Row, RX` + `DrilldownGroup`（内嵌 `ShowSubsidiary.aspx` 链接参数）。

### 2.13 Attachment & Audit History（附件与审计轨迹）
- **Attachments (`E07`):** 单文件上传上限 **25 MB**，关联至多态 `TargetType + TargetID`，并可复用于 Document Library (`Files`)。
- **History & Notes (`E03`, `E07`, `E37`):** 只增不改的时间线事件流，记录创建、批准、编辑字段前后对比（如 `from no value to Tax Inclusive`）、锁账变更（`Lock date (for all users) - added '31 Oct 2026'` / `- removed`）与人工备注。

### 2.14 BankRule & UserAccess RBAC（银行规则与权限矩阵）(`E31-PAGE`, `E34-PAGE`)
- **BankRule (`/bank-rules/create`):** 5 段结构：`MatchConditionOperator` (`ANY | ALL`), `Conditions[]` (`Field`, `Operator`, `Value`), `ContactID`, `Allocations[]` (`IsFixedAmount` 固定额优先 + 剩余 `%` 分摊, `AccountID`, `TaxType`), `ReferenceSource`, `BankAccountScope` (`Single | All`)。
- **UserAccess (`/settings/user-access`):** 9 种角色（`Subscriber`, `Administrator`, `Standard`, `Payroll admin`, `Invoice only`, `Expenses`, `Read only`, `Project admin`, `Projects standard`）映射多域权限开关；其中 `Standard` 默认不含 `Accounting -> Lock dates` 与 `Cash coding`，须 `Administrator` 角色解锁。
